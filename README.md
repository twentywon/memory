# 차곡

국기·수도, 한국의 역대 왕, 영어 단어를 공부하는 개인 암기 웹 앱입니다.

## 실행

Node.js 20 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`로 데이터와 학습 방향 변환을 검사합니다.

## 사용

주제 선택 → 공부하기 또는 테스트하기를 선택합니다. 학습 방향과 왕조를 바꿀 수 있으며, 테스트에서는 각 행의 정답을 따로 공개합니다. 섞기와 다시 시작도 지원합니다. 현재 학습 상태는 페이지를 새로고침하면 초기화됩니다.

초기 데이터: 24개국, 고구려·백제·신라·고려·조선의 왕 순서, 영어 단어 20개. 한국사 전체 국가를 망라하지는 않습니다. 신라는 통일 이전과 이후를 함께 포함하며, 조선의 마지막 두 군주는 대한제국 황제 재위까지 이어집니다. 스위스 베른은 연방시입니다. 국기는 운영체제의 이모지 지원에 따라 표시됩니다.

## 확장

`data.js`에서 나라, 단어, 왕 목록을 추가할 수 있습니다. 화면과 동작은 `app.js`, 디자인은 `style.css`에 있습니다. 외부 API나 비밀 키는 필요하지 않습니다.

## 컴퓨터에서 설치 없이 시연

`demo/index.html`을 내려받아 더블클릭하면 브라우저에서 실행됩니다. 인터넷이나 Node.js가 필요하지 않습니다. 개발 소스를 수정했다면 `npm ci && npm run build`로 시연 파일을 갱신하세요.

## Android APK

Capacitor 7 기반 Android 앱 프로젝트가 `android/`에 있습니다. Java 21, Android SDK 35, Node.js 20 이상을 준비하세요. SDK 경로는 `ANDROID_HOME` 또는 로컬 `android/local.properties`의 `sdk.dir`로 설정합니다.

```sh
npm ci
npm run android:apk
```

결과: `android/app/build/outputs/apk/debug/app-debug.apk`. 개인 시연용 디버그 서명 APK입니다. 스토어 배포용 릴리스 서명은 별도입니다. Android 6.0 이상을 지원합니다. Android Studio에서 `android/`를 열어 가상 기기를 만든 뒤 APK를 설치하면 컴퓨터에서도 Android 버전을 시연할 수 있습니다. 실기기에서는 APK를 전송해 설치하세요. 국기 이모지는 기기 폰트에 따라 표시가 달라질 수 있습니다.
