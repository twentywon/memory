# 대한민국 행정구역 학습 자료

공개 주소 트리 `Guk0/KoreanAddressJson/address2.json`에서 시·군·구 수준을 추출하고 편집한 목록입니다. 원본 URL, 체크섬, 수집일과 보정 내역은 `sources.json`에 있습니다. 원본의 모든 읍·면·동이나 위치 좌표를 앱에 싣지는 않습니다.

- 17개 광역자치단체.
- 시·군·자치구 227개, 제주 행정시 2개, 일반구 39개: 소속 관계 268개.
- 자치구와 일반구를 구분합니다. 일반구는 `수원시 영통구`처럼 도시 이름을 함께 제시합니다.
- 세종특별자치시는 단층제라 가상의 하위 시·군·구를 만들지 않습니다. 해당 필터에서는 빈 목록과 설명을 표시합니다.
- 같은 이름은 하나의 문제로 묶고 가능한 시·도를 모두 정답으로 표시합니다. 예: `고성군 → 강원특별자치도 · 경상남도`.
- 시·도 필터는 해당 지역과 관련된 항목을 보여 줍니다. 동명 지역의 정답은 다른 가능한 시·도까지 함께 유지합니다.

원본은 과거 주소 목록이므로 아래 변경을 수동 반영했습니다.

- 군위군의 대구광역시 편입 (2023).
- 강원특별자치도·전북특별자치도 명칭.
- 부천시 일반구 복원 (2024).
- 화성시 일반구 만세구·효행구·병점구·동탄구 (2026).
- 인천광역시 제물포구·영종구·검단구 개편 (2026-07-01). 옛 중구·동구 항목을 제거하고 서구는 유지합니다.

행정안전부의 실시간 공식 코드 API와 연결된 서비스가 아닙니다. 편집한 학습 자료로 제공하며 최신 법령·행정구역 공지는 행정안전부와 각 지자체에서 확인해야 합니다. 검증 기준으로 현재의 지역 엔티티 수와 대표 개편을 테스트합니다.
