# 오프라인 대한민국 행정구역 지도

- 원자료: 통계청 통계지리정보서비스(SGIS), 공공누리 제1유형(출처표시).
- 공개 가공 자료: https://github.com/vuski/admdongkor
- 사용한 경계: `ver20260401/HangJeongDong_ver20260401.geojson`.
- 가공물: CC BY 4.0. 원본 `LICENSE-DATA`에 원자료 조건과 출처표시 의무를 보존했습니다.
- 수집 날짜, SHA-256, 원본 주소: `sources.json`.

행정동 폴리곤을 원본의 시군구·시도 코드로 합쳐 시도 17개와 시군구 경계 255개를 만들었습니다. 위상을 보존해 단순화하고 메르카토르 투영 SVG 경로로 변환했습니다. 지도를 이미지로 임의로 그리거나 지역 위치를 추정하지 않았습니다. 작은 지역은 지도 아래의 이름 목록에서도 선택할 수 있습니다. 확대·축소, 끌어서 이동, 이름 표시 기능을 제공합니다. 경계는 원본 폴리곤을 합쳐 생성하므로 도 지도에서는 시 내부의 구 경계선도 숨깁니다.

**날짜 차이:** 지도는 2026-04-01 경계입니다. 행정구역 퀴즈의 편집 목록은 인천 2026년 7월 개편을 반영하므로, 인천 지도에는 아직 옛 중구·동구·서구 경계가 표시됩니다. 전국 지도와 인천 상세 지도 모두 기준일·차이를 안내합니다. 세종은 하나의 경계로 표시하며 가상의 하위 시군구를 만들지 않습니다. 일반구가 있는 13개 도시는 도 지도에서 경계를 합쳐 시 이름 하나만 표시합니다. 해당 시의 경계 또는 목록을 누르면 별도 시 지도로 들어가 구의 경계·이름을 볼 수 있습니다. 구는 상세 화면에서 시 이름을 반복하지 않고 표시합니다. 뒤로 이동은 시 지도→도 지도→전국 지도 순서입니다. 학습·위치 이해용 자료로, 측량·법적 경계 판단용이 아닙니다.

경계 재생성에는 Python 3, Shapely 2.1.2와 원본 GeoJSON이 필요합니다.

```sh
python scripts/build-region-maps.py /path/to/HangJeongDong_ver20260401.geojson
npm run build
```

원본 날짜를 바꿀 때 시도·시군구 변경과 퀴즈 목록의 차이도 함께 검토해야 합니다.

시 상세 지도(13개): 수원·성남·안양·부천·안산·고양·용인·화성·청주·천안·포항·창원·전주. 서울 등 특별시·광역시의 자치구는 기존처럼 해당 시도 지도에 표시하며, 제주 행정시와 세종도 기존 경계를 유지합니다. 원래 시군구 255개는 도 지도 및 시 상세 지도를 합쳐 모두 보존합니다.
