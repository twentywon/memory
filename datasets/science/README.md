# 원소와 주기율표

원자료: https://github.com/Bowserinator/Periodic-Table-JSON

원자번호, 이름, 기호, 주기·족, 좌표와 분류를 선택해서 사용했습니다. 원본은 CC BY-SA 3.0으로 제공되며 라이선스는 `ELEMENTS-LICENSE.md`에 보존했습니다. 출처와 수집일, 원본 체크섬은 `sources.json`에 있습니다. 이 원소 파생 데이터 역시 같은 라이선스로 제공합니다.

- 국제적으로 인정된 원자번호 1~118번만 포함합니다. 원본에 있는 미확정 119번은 제외합니다.
- 원소 이름은 한글 편집 표기이며 나트륨/소듐, 칼륨/포타슘, 플루오린/불소 등 통용명을 참고로 표시합니다.
- 이름→기호, 기호→이름의 두 방향을 제공합니다. 기호의 대소문자를 유지합니다.
- 주기율표는 18열이며 란타넘족·악티늄족을 아래 두 줄에 따로 표시합니다. 각 칸을 누르면 상세 정보를 표시합니다.
- 분류 미확정 원소는 분류 미확정으로 표시합니다. 원자량·화학적 성질을 별도로 추정해 넣지 않습니다.
