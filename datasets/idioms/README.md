# 사자성어 확장 목록

- 추가 공개 자료: https://github.com/LiF-Lee/idioms
- MIT License, Copyright (c) 2021 EliF. `LICENSE`에 전문 보존.
- 원본 2,318개 항목: `original.json`.
- 기존 편집 목록 65개: `curated-base.json`.
- 출처 URL, 수집 날짜, 원본 체크섬, 제외 건수: `sources.json`.

기존 65개는 ID·표기·풀이를 그대로 보존했습니다. 추가 자료에서 한글 4음절·한자 4자와 비어 있지 않은 뜻을 가진 항목을 선택하고 한글 표현 및 유니코드 호환 한자 기준으로 중복·변형을 제거했습니다. 최종 2,307개 표현입니다. 새 항목의 ID도 표현에서 결정적으로 생성합니다. 기존 오답 기록을 삭제하거나 다시 번호 매기지 않습니다.

공식 사전이나 시험 범위의 완전한 목록이라고 주장하지 않습니다. 공개 자료의 고전적·드문 표현을 포함하며 뜻·독음이 다른 통용 표기와 다를 수 있습니다. 의미가 겹치는 표현은 자기 채점으로 복습합니다. 기존 풀이와 새 출처가 겹치면 기존 편집 풀이를 우선합니다. 공부 화면에는 표현·한자·뜻 검색을 제공하고, 테스트는 검색과 무관하게 전체 목록에서 무작위로 출제합니다.

```sh
npm run idioms:refresh
npm test
```

이 스크립트는 공개 MIT 자료를 다시 수집하고 기존 목록과 합칩니다. 특정 사전 전체를 무단 복제하거나 웹에 존재하는 모든 사자성어를 수집한 기능은 아닙니다.
