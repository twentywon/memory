# 한국어문회 급수별 한자

- 원자료 분류·저작권: 사단법인 한국어문회 https://www.hanja.re.kr/
- 수집한 공개 변환 자료: https://github.com/rycont/hanja-grade-dataset
- 원본 CSV URL과 SHA-256, 수집 날짜, 실제 급수별 개수: `sources.json`
- 다운로드 원본: `original.csv`
- 앱 데이터: `../hanja.js`

공개 변환 자료는 한국어문회 홈페이지의 공식 XLS 파일을 CSV로 변환한 자료라고 설명합니다. 이 환경에서는 한국어문회 사이트 본문에 직접 접속할 수 없어 해당 공개 미러를 사용했습니다. 저작권을 별도로 허여받았다고 주장하지 않으며 출처·권리 안내를 유지합니다. 최신 시험 배정 변경 여부는 한국어문회 공지와 확인해야 합니다.

8급 50자 목록은 별도 공개 자료 `kyeongmin/KoreaHanja/data/kles/level8.json`과 공백·유니코드 호환 한자를 정규화해 교차 확인했습니다. 앱에서는 원본 한자 자형과 복수 음훈을 보존합니다. CSV의 중첩 리스트를 안전한 `ast.literal_eval`로 읽고 음훈을 조합합니다. 미러 README의 특급·특급Ⅱ 개수 표에는 뒤바뀐 값이 있으므로 README가 아닌 CSV의 실제 급수 배정을 사용했습니다.

| 급수 | 새 배정 | 누적 |
|---|---:|---:|
| 8급 | 50 | 50 |
| 7급Ⅱ | 50 | 100 |
| 7급 | 50 | 150 |
| 6급Ⅱ | 75 | 225 |
| 6급 | 75 | 300 |
| 5급Ⅱ | 100 | 400 |
| 5급 | 100 | 500 |
| 4급Ⅱ | 250 | 750 |
| 4급 | 250 | 1,000 |
| 3급Ⅱ | 500 | 1,500 |
| 3급 | 317 | 1,817 |
| 2급 | 538 | 2,355 |
| 1급 | 1,145 | 3,500 |
| 특급Ⅱ | 1,150 | 4,650 |
| 특급 | 1,328 | 5,978 |

급수Ⅱ는 해당 급수의 준급수 표기입니다. 한자→음훈, 음훈→한자 학습을 지원하고 하위 급수 누적 또는 새 배정만 선택할 수 있습니다. 페이지는 50자 단위이며 테스트는 선택 범위 전체를 무작위로 섞은 뒤 페이지를 나눕니다.

갱신: `npm run hanja:refresh` 후 `npm test`.
