# 차곡

국기·수도, 국가별 왕과 지도자, 단어장별로 직접 등록하는 영어 단어를 공부하는 개인 암기 앱입니다. Android APK와 컴퓨터용 오프라인 HTML 시연을 지원합니다.

## 컴퓨터에서 바로 시연

`demo/index.html`을 내려받아 더블클릭하세요. 이미지까지 포함된 단일 파일이라 서버, Node.js, 인터넷 연결이 필요하지 않습니다. 개인 기록은 파일을 여는 브라우저의 저장소에 남습니다. 브라우저나 파일 위치를 바꾸면 기록이 다르게 보일 수 있으므로 홈의 **단어·오답 기록 내보내기**로 백업하세요.

## 개발

Node.js 20.19 이상 권장 (검증: 24), npm을 사용합니다.

```sh
npm ci
npm start
```

기본 포트는 3000이며 `PORT`로 바꿀 수 있습니다. 외부 API나 비밀 키는 필요하지 않습니다.

```sh
npm test          # 빌드 + 데이터·저장·화면 동작 테스트
npm run build     # www/, dist/chagok-demo.html, demo/index.html 갱신
npm run data:refresh  # HTTPS 원본에서 국가 데이터 및 SVG 국기 재수집 (Python 3, curl 필요)
```

## 학습 기능

- **국기와 수도**: 기본 195개국(유엔 193개국 + 바티칸·팔레스타인). 전체 범위로 비회원 국가·속령 등을 포함한 250개 국가·지역 선택 가능. 7개 대륙 필터(기본 195개국 중 남극 국가는 없음), 국기·국가명·수도를 각각 분리한 여섯 방향(국가명→수도, 국가명→국기, 수도→국가명, 수도→국기, 국기→국가명, 국기→수도). 중앙아메리카·카리브해는 북아메리카에 포함합니다. 수도명은 전체 한글 표기로 표시하며 원본 영문은 데이터에 보존합니다. 복수 수도는 모두 표시합니다. 수도가 없는 지역은 수도를 포함한 테스트에서만 제외합니다. 250개 SVG 국기를 앱에 포함했습니다.
- **왕과 대통령 (한국)**: 고구려·백제·신라·고려·조선의 기존 왕 176명과 대한민국 대통령 14명. 재위·재임 기간을 참고 정보로 표시합니다. 고대 초기 기년에는 사료별 차이가 있습니다. 고려 복위 기간을 따로 표시하고 대통령은 동일인 연임을 묶어 표시합니다. 대통령 권한대행은 제외합니다. 현재 재임 기준: 2026-10-16. 한국의 모든 역사 국가를 망라하지는 않습니다.
- **나의 영어 단어장**: 텝스, 미드 LOST 등 이름을 붙여 여러 단어장을 생성·이름 변경·삭제합니다. 단어장마다 단어와 뜻을 직접 추가·삭제하고 양방향으로 학습하며, 오답도 해당 단어장 단어만 모아 재시험합니다. 미리 등록된 단어는 없습니다. 기존 버전의 단어와 오답은 ID를 유지한 채 `기존 단어장`으로 자동 이전합니다.
- **해외 지도자**: 국가 선택에서 중국·미국·영국·프랑스·독일·일본을 선택합니다. 미국 대통령 47개 재임, 영국 총리 55개 재임, 프랑스 공화정 대통령 25명, 독일 바이마르 총리 14개 재임·연방총리 10명, 중국 중화민국 임시·북양정부 16개·국민정부 및 총통 9개·중화인민공화국 12개, 일본 총리대신 80개 재임 항목입니다. 비연속 재임은 별도 행, 연속 연임·내각은 묶었습니다. `재임 순서`는 공식 대통령 대수나 내각 대수가 아닙니다.
- **자기 채점**: 국가·영어 테스트에서 정답을 공개한 뒤 초록 **맞음**, 빨강 **틀림** 선택. 색과 함께 문자·체크 표시를 제공합니다. 공개만으로는 채점하지 않습니다.
- **오답노트**: 주제와 학습 방향별로 틀린 문제만 재시험. 단어는 선택한 단어장으로 한정합니다. 국가 오답에는 대륙·국가 범위 필터도 적용합니다. 맞음으로 바꾸면 해당 방향의 오답에서 제거됩니다. 재시험 도중에는 문항을 유지하고 다음 재시작 시 반영합니다.

단어와 오답은 `localStorage`에 저장됩니다. 로그인·클라우드 동기화는 없습니다. 홈에서 JSON 텍스트로 백업·복원하거나 JSON 파일을 가져올 수 있습니다. 복원은 기존 기록을 유지하며 합칩니다. 브라우저 데이터 삭제·앱 삭제 전에 백업하세요. 저장소를 쓸 수 없으면 경고를 표시합니다.

## 해외 지도자의 수록 기준

- 중국: 사용자 지정에 따라 1912년 중화민국부터 수록합니다. 북양정부·국민정부의 병존을 별도 목록으로 나누고, 중화민국 목록은 대륙 정부 이행기(1949–1950)까지입니다. 이후 중화인민공화국 국가수반을 별도 목록으로 표시합니다. 국가주석 폐지기에는 전인대 상무위원장·집단 국가수반을 표시합니다. 중화인민공화국 수립을 민주화로 규정하지 않습니다.
- 미국: 1789년 헌법상 첫 대통령부터.
- 영국: 민주화가 단계적이므로 1832년 선거법 개정 당시 재임 중인 그레이(1830 취임)부터 총리를 수록합니다.
- 프랑스: 대통령직이 생긴 제2공화국(1848) 및 제3·4·5공화국. 제정·비시·과도정부·권한대행은 제외합니다.
- 독일: 바이마르공화국(1919–1933) 총리 및 연방공화국(1949 이후, 서독→통일 독일) 총리. 나치·동독·임시 권한대행 제외.
- 일본: 메이지 유신(1868) 이후 내각제가 생긴 1885년부터 총리대신. 전전·전후를 포함하며 이를 단일 민주화 시점으로 간주하지 않습니다. 임시대리 제외.

해외 목록은 **2025년 취임 인물까지의 고정 편집 자료**이며 실시간 현직 목록이 아닙니다. 끝 연도가 빈 항목은 종료일 미수록입니다. 국가별 범위와 참고 링크는 앱과 `datasets/leader-catalog.js`에 있습니다. 원문을 자동 수집한 자료가 아닌 수동 정리 데이터이며, 이후 인사 변동은 별도 갱신이 필요합니다.

기존 국가 오답은 새 방향으로 이전합니다. 기존 `forward`는 국가명→수도, `reverse`는 수도→국가명/국기, `flag`는 국기→국가명/수도로 보존합니다. 과거에 답 두 가지를 함께 묻던 오답은 둘 다 복습할 수 있도록 두 방향에 남깁니다. 백업은 단어장 경계까지 보존하고 ID가 충돌하면 기존 기록을 유지하며 새 ID로 합칩니다.

## Android APK

Java **JDK** 21(컴파일러 포함), Android SDK platform 35, build-tools 34.0.0, Node.js 20.19 이상을 준비하세요. SDK 위치는 `ANDROID_HOME` 또는 `android/local.properties`의 `sdk.dir`로 설정합니다.

```sh
npm ci
npm run android:apk
```

결과: `android/app/build/outputs/apk/debug/app-debug.apk`. Android 6.0 이상용 개인 시연용 디버그 서명 APK입니다. 스토어 배포용 릴리스 서명은 별도입니다. Android Studio에서 `android/` 프로젝트를 열고 Device Manager로 가상 기기를 실행한 뒤 APK를 끌어다 놓으면 컴퓨터에서 Android 버전을 시연할 수 있습니다. 실기기는 APK를 전송해 설치합니다. 웹과 APK의 개인 기록은 서로 다른 저장소에 보관됩니다.

## 데이터 출처와 구조

출처, 범위, 라이선스: [datasets/SOURCES.md](datasets/SOURCES.md). 국가 데이터는 mledoze/countries(ODbL), 국기는 hampusborgos/country-flags의 SVG를 HTTPS로 수집했습니다. 수집 일시와 원본·국기 체크섬은 `datasets/country-sources.json`에 있습니다. 역사 연표는 참고자료를 바탕으로 수동 정리했습니다.

- `app.js`: 화면과 사용자 동작
- `data.js`: 학습 카드 변환과 필터
- `storage.js`: 개인 단어·오답 저장 및 검증
- `datasets/countries.js`, `datasets/capitals-ko.js`, `datasets/history.js`, `datasets/leaders.js`, `datasets/leader-catalog.js`: 국가·역사 데이터
- `assets/flags/`: 수집한 실제 국기 SVG
- `scripts/build.mjs`: 앱용 정적 파일과 이미지 내장 시연 HTML 생성

데이터 변경 후 `npm test`와 `npm run android:apk`로 시연 HTML과 APK를 갱신합니다.
